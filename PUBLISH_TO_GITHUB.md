# Publish this project to GitHub

## Easiest method: GitHub website

1. Sign in at https://github.com/
2. Click **New repository**.
3. Suggested repository name:

   `CFMOTO-RIDE-to-GPX`

4. Suggested description:

   `Repeatable BlueStacks/ADB workflow for exporting your own CFMOTO RIDE historical tracks to GPX.`

5. Choose **Public** if you want anyone to access it.
6. Do **not** initialize it with another README if you are uploading this package.
7. Create the repository.
8. On the empty repository page, choose **uploading an existing file**.
9. Upload the contents of this package.
10. Commit the files.

## Before publishing

Make sure you are NOT uploading:

- `ride_capture.txt`
- another raw logcat file
- `.har`
- `.mitm`
- personal `.gpx` tracks
- screenshots containing private information
- tokens or account IDs

The repository already contains `.gitignore` rules for the common capture files.
